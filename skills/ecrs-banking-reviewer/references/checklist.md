# 审阅质量检查清单

在输出审阅报告前，逐项检查以下内容。

## 完整性

- [ ] 四个维度（取消、合并、重排、简化）都已分析
- [ ] 流程中的每个步骤都在至少一个维度中被评估
- [ ] 长文档场景下，所有分段都已完成分析
- [ ] 无遗漏的流程片段未审阅

## 取消分析

- [ ] 对每个建议取消的环节，给出了明确的取消依据
- [ ] 对每个建议取消的环节，进行了风险评估
- [ ] 确认被建议取消的环节不是监管强制要求
- [ ] 没有被取消的环节导致流程不完整的风险

## 合并分析

- [ ] 被建议合并的环节确实可以合并执行
- [ ] 合并后不会导致岗位分离/双人操作被违反
- [ ] 给出了合并方案和预期效果

## 重排分析

- [ ] 重排后的步骤之间没有逻辑依赖冲突
- [ ] 并行执行的步骤之间确实无前置依赖
- [ ] 重排不会导致风险控制的缺失

## 简化分析

- [ ] 简化方案具体可执行，不是笼统的"提高效率"
- [ ] 简化不会降低合规/风控标准
- [ ] 评估了简化方案的实施成本

## 报告质量

- [ ] 每个建议都有依据、效果评估和风险说明
- [ ] 优化后的流程从触发到产出完整闭环
- [ ] 优化后流程的步骤清单完整
- [ ] 预期效果有具体数据支撑（步骤数、时长等对比）
- [ ] 实施路线图按难度和时间合理分层
- [ ] 风险提示中包含合规确认

## 长文档场景额外检查

- [ ] 分段方案已向用户说明并获得确认
- [ ] 每段分析都携带了全局上下文
- [ ] 跨段建议已去重（同一条建议不在多段中重复出现）
- [ ] 全局性问题已识别（贯穿多个子流程的问题）
- [ ] 合并后的报告覆盖了所有分段

## 禁止项

- [ ] 没有建议取消监管强制要求的环节
- [ ] 没有对可取消的环节只做简化（ECRS 顺序正确）
- [ ] 没有缺乏依据的主观判断
- [ ] 没有建议违反岗位分离/双人操作要求

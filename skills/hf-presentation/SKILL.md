# HyperFrames Presentation Generator

Interactive skill that creates a Swiss Grid style HTML video presentation. Ask the user questions to gather requirements, then generate config.json and run the generator.

## When to Use

- User wants to create a presentation, video deck, or animated slideshow
- User mentions "presentation", "slide deck", "video presentation", "Swiss Grid", "corporate video"
- User wants to turn text/content into an animated HTML video

## Template Location

├── scripts/generate.py  ← generates index.html

## Interactive Flow

### Step 1: Gather Basic Info

Ask the user (one batch of questions):

1. **Presentation title** — the main title shown on the opening card
2. **Number of scenes** — how many scenes/chapters (3-15 typical)
3. **Output directory** — where to save (default: `D:\Claude Code\Work\<project-name>`)

### Step 2: Gather Scene Content

For EACH scene, ask:

1. **Section label** — e.g. "MISSION 01 / INNOVATE", "WHY IT MATTERS"
2. **Scene title** — the big headline (supports `<em>` for accent highlighting)
3. **Keywords** — 3-5 short phrases shown on the left column (supports `<em>`)
4. **Narration** — the voiceover text (will be auto-split into subtitle lines)
5. **Image path** — path to illustration PNG (or "none" if not ready)
6. **Status label** — small status text in top-right corner

**Batch scenes when possible** — if the user provides content for multiple scenes at once, process them all.

### Step 3: Generate Config

After gathering all scene data:

1. Copy the template directory to the output directory
2. Write `config.json` with all scene data
3. Run `python scripts/generate.py` to generate `index.html`
4. Report the output file path and timing summary

### Step 4: Optional Enhancements

Ask if the user wants to:
- **Generate TTS** — use MiMo V2.5 TTS (`mimo-v2-5-tts` skill) to create voiceover audio
- **Adjust design** — change colors, fonts, title card duration
- **Render MP4** — run the render pipeline

## TTS Generation

When the user wants TTS, use the `mimo-v2-5-tts` skill to generate voiceover for each scene's narration text. Save output as `assets/audio/vo-01.mp3` through `assets/audio/vo-XX.mp3`.

## Render Pipeline

```bash
# 1. Generate HTML
cd "D:\Claude Code\Work\<project>"
python scripts/generate.py

# 2. Render video (puppeteer + FFmpeg)
bash scripts/render.sh output.mp4

# 3. Add audio (background music + TTS)
bash scripts/add-audio.sh output.mp4 final.mp4

# Or use HyperFrames CLI:
npx hyperframes render --output final.mp4
```

## Important Notes

- **Static HTML for subtitles** — subtitle lines must be pre-rendered in HTML, not dynamically created via JS (HyperFrames seek mode requirement)
- **GSAP fromTo()** — always use `gsap.fromTo()` not `gsap.to()` for initial state animations
- **window.__timelines** — must register the GSAP timeline for HyperFrames rendering
- **Audio loop** — background music loops via FFmpeg `-stream_loop -1`, not HTML `loop` attribute
